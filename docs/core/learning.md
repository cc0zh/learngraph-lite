# 节点教学、练习与掌握度

节点承载学习积累，会话承载独立聊天。Agent 可以解释和生成学习内容，正式判分、掌握度和下一步建议由程序规则决定。

## 本页解决什么问题

- 浏览一个节点，是否就切换了当前对话？
- 同一节点开两个对话，哪些数据独立、哪些共享？
- 聊天、阅读和正式作答，哪一种会改变成绩？

## 用一个例子开始

在已发布图谱的“检索”节点点击“开始学习此节点”，建立对话 A；之后再为同一节点建立对话 B。A、B 的聊天记录分别保存，但在 A 中生成的正式练习、学习包和作答成绩，B 也能读取，因为这些积累属于目标与节点。

如果你在右侧浏览“文档切块”，A 仍然是“检索”的对话。需要学习另一个节点时，要显式开始它的学习对话，不能靠浏览位置或 URL 改绑当前会话。

## 正常流程

```text
选择已发布节点 → 开始或继续对话
                       ↓
              解释 / 学习包 / 正式题目
                       ↓ 用户交卷
              程序判分 → 掌握度与建议
```

Agent 的口头提问不自动成为正式练习。正式题目须通过生成用例校验保存，未作答前不公开正确选项。提交答案后，程序根据服务端答案返回反馈，不再调用模型来决定对错。

## 谁决定，保存什么

| 内容或动作 | 归属与作用 |
| --- | --- |
| 聊天记录、输入草稿 | 各会话独立，不自动跨会话合并历史 |
| 教材、正式题目、作答 | 归目标与节点，按内容版本校验 |
| 正式交卷 | 保存作答反馈；同题重复作答不反复增加计分样本 |
| 阅读、点击、自述“已掌握” | 不作为正式学习成绩 |
| 下一步建议 | 从有效作答和前置规则计算；查看推荐节点不自动创建对话 |

例如三道不同正式题首次作答全对，可以达到当前规则的练习熟练标准；同一题重复答对三次仍只有一个计分样本。这是练习表现，不是能力认证。精确窗口、阈值和推荐顺序见[评分与推荐规则](../developer/concepts.md#正式练习、掌握度与推荐)，不要在 prompt 或前端另写一套权威评分。

## 遇到问题先看这里

- **重开对话没有旧聊天：**这是会话隔离，不代表节点学习积累丢失。
- **题目可读但不能再答：**检查图谱内容版本；旧题反馈保留，不接受新的过期作答。
- **点击推荐后没有开始教学：**推荐浏览与新建学习对话是两次操作，避免无意触发模型。
