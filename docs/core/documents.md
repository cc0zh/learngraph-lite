# 资料检索与引用

资料学习包含四个不同动作：上传、绑定、检索和引用定位。文件存在不等于当前节点可以使用它，引用可定位也不等于模型的结论已经被原文证明。

## 本页解决什么问题

- 为什么上传资料后，还要绑定目标与节点？
- 回答、练习和学习包里的 C1 能不能混用？
- 来源有效到底验证了什么，没有验证什么？

## 用一个例子开始

上传一份“检索笔记”，待解析成功后先绑定到 RAG 学习目标，再显式绑定到“检索”节点。目标绑定可供图谱生成使用；节点问答、练习与学习包只使用该节点明确绑定的资料，不自动继承所有目标资料。

在工作台“我的资料”中管理上传和原文，通过目标或节点资料入口检查绑定；这些工具不会改变当前聊天的目标与节点。

## 正常流程

```text
上传 TXT / Markdown / 文本型 PDF
                    ↓ 本地解析与索引
           绑定目标 → 显式绑定节点
                    ↓ 当前范围内检索
           回答或学习产物保存来源
                    ↓ 点击引用
           复验来源 → 定位原文片段
```

上传与解析不调用模型。Agent 检索时只看本次业务范围允许的资料；资料内容是数据，不能覆盖系统指令或扩大工具权限。引用点击后按当前绑定与来源状态重新验证，不是直接信任模型给出的链接。

## 谁决定，保存什么

- **用户决定资料范围：**上传不自动绑定；目标绑定不自动覆盖所有节点。
- **程序保存来源：**回答、图谱、题目和学习包各自拥有来源表，包含文档、片段、版本、位置和内容摘要等定位信息。
- **引用编号是局部的：**回答的 C1 和练习的 C1 可以指向不同笔记，必须从各自产物进入原文，不能合并成“当前会话 C1”。
- **有效不等于语义正确：**来源验证核对绑定、版本、内容和位置，不能证明原文支持模型推导；仍需要阅读原文判断。

## 遇到问题先看这里

- **资料没有参与回答：**先检查解析状态和当前节点绑定，不只确认上传列表里有文件。
- **生成没有找到资料就失败：**有绑定但未检索到片段时，资料型生成不会静默改成通用生成；可检查绑定与资料内容。
- **旧引用无法定位：**解绑、删除或来源过期可能使引用失效；完成时的来源快照不保证永远可定位。
- **扫描 PDF 没有文字：**当前不支持 OCR 或 Office 导入，请使用受支持的文本格式。
