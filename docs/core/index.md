# 核心机制总览

这里按能力解释 LearnGraph Lite 如何工作，不要求先认识类名或读完源码。第一次使用请先[启动无 Key 工作台](../developer/getting-started.md)；准备修改功能时，再进入[领域概念](../developer/concepts.md)、[架构地图](../developer/architecture.md)和[关键调用链](../developer/flows.md)。

## 用一条学习闭环理解系统

```text
学习意图 → Agent 澄清与目标草稿
                    ↓ 用户确认
           图谱草稿与审核发布
                    ↓ 选择节点并开始学习
           对话 / 学习包 / 正式练习
                    ↓ 提交答案
           程序判分 → 掌握度与建议
```

资料检索为规划和学习提供来源，Skill 为交互 Agent 提供按需指南，运行层负责模型与工具执行、状态保存及显式恢复。它们都不能绕过用户确认、业务作用域和正式评分规则。

## 按你关心的问题进入

| 你的问题 | 阅读入口 | 读完应能说清 |
| --- | --- | --- |
| AI 生成之后，为什么还要确认和发布？ | [目标规划与图谱审核](planning.md) | 草稿、用户决定与已发布图谱的区别 |
| 在同一节点重开对话，会丢掉学习积累吗？ | [节点教学、练习与掌握度](learning.md) | 独立聊天与节点共享状态的边界 |
| 上传了资料，为什么回答没有使用它？ | [资料检索与引用](documents.md) | 上传、绑定、检索与引用验证的区别 |
| 阅读、切步骤、追问和交卷分别改变什么？ | [学习包与交互解释](lessons.md) | 阅读事件、解释任务与正式成绩的区别 |
| 刷新、取消或重启之后，任务会怎样？ | [Agent 执行、取消与恢复](agent-loop.md) | 查询、恢复原请求与重试失败任务的区别 |
| 怎么选择和新增流程指南？ | [应用 Agent Skill](../agent-skills.md) | 按需加载、适用模式与权限限制 |

例如学习“RAG 的检索部分”：先审核 `文档切块 → 检索` 图谱，再在检索节点开独立对话；把笔记显式绑定到这个节点，用学习包阅读并提交正式练习，最后查看反馈与建议。只想查某一步时，直接打开对应机制页，不必按目录从头阅读。
