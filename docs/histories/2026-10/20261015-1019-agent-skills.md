# 共享 Agent Skill 支持

## 用户诉求

参考 nanobot，在当前项目增加 Skill；规划与节点学习共享技能机制，不创建新的 Agent 引擎。

## 结果

增加可信 Markdown 技能目录、安全 YAML 启动快照、受限 read_skill、当前用户显式选择、场景过滤、共享预算、使用元数据和旧历史正文投影；内置 goal-planning 与 concept-teaching。保留工具授权和业务边界，不开启脚本、自动安装或内层生成指导。

完整文件、决定、审查修复和验收记录见[执行计划](../../exec-plans/completed/agent-skills.md)；新增步骤见[技能说明](../../agent-skills.md)。
