# 默认规划改为 Agent 主导

## 用户诉求

用户对比 LearnGraph 后明确偏好 Agent 主导：目标确认到图谱确定应是连续协作，而不是固定问卷后调用生成器；授权按该方向实施优化。

## 结果

新增专用原生工具规划 Agent、动态问题/目标/路线审核卡、结构化回答与持久协议历史；目标明确确认后推进图谱生成，自然语言解释与修订展示实际差异。模型无确认/发布能力，问题卡由宿主结束轮次，旧卡/版本/取消/恢复边界保留。默认 UI 改为对话主线，旧向导保留为可选手动入口；长对话内部滚动、窄屏对话优先。

完整实施、文件与失败修复/验证证据见[执行计划](../../exec-plans/completed/agent-led-planning.md)。本次仅 fixture/离线验证，不调用付费模型，不以历史真实 P0 证据证明新规划语义质量。
