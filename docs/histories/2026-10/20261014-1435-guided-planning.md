# 引导式目标澄清与可理解路线确认

## 用户诉求

允许从不完整学习意图开始，通过少量关键问题、选项/自定义/跳过形成可修改且明确确认的摘要；展示假设而不把自述包装成能力。普通用户按阶段、成果、投入和必要性确认路线，可反馈调整，保留可选高级图谱编辑，发布仍须明确确认。

## 结果

已实现三问引导、一次摘要确认、透明跳过与假设、阶段式路线投影和反馈生成新草稿；保留版本校验、显式发布、独立编辑保护和请求恢复边界。同步产品规格、API 使用说明、架构和测试。
