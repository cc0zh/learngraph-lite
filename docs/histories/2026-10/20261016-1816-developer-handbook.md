# 开发者文档与同源文档站

## 用户诉求

参考 CountBot 的文档组织，为当前项目梳理开发者文档，帮助新人启动、理解并独立修改业务；在本地分支实施，同一份 Markdown 同时用于仓库阅读与文档站，不公开部署。

## 结果

新增总览与九页开发者指南，按当前单工作台源码核对概念、六条调用链和修改入口；接入 VitePress 中文本地搜索、导航、同源相对链接及独立浏览器测试。同步贡献、README 与 CI，补齐缓存排除和源码归档回归。保留既有规范、历史与当前质量状态入口，不把参考项目能力或旧验收等同于本项目当前能力。

文件范围、设计取舍、实际检查与未测项统一见[完成计划](../../exec-plans/completed/developer-handbook.md)。主体实现已包含在 `7e40be9`，本次按用户要求提交文档收尾记录；未发布或部署。
