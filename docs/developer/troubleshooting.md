# 常见问题与排错

先保存现象、入口、模式与非敏感错误，再查对应边界。不要通过清库、换 request ID 或关闭安全校验来“解决”未知问题。

## 环境与启动

| 现象 | 排查与处理 |
| --- | --- |
| PowerShell 阻止 npm.ps1 | 改用 `npm.cmd` / `npx.cmd`，不必降低全局执行策略 |
| 无法解析 uv 或 Python 版本不符 | 检查 uv 安装与终端 PATH，执行 `uv sync --locked --group dev` |
| `SQLite FTS5 is required` | 用[首次运行](getting-started.md)的内存探针检查；更换支持 FTS5 的 Python 后重新建立项目虚拟环境 |
| Web 能打开但业务 API 404 | 确认用 `dev` / `dev:api:business`，不是仅支持 echo 的 `dev:api` |
| 端口已占用或 E2E 拒绝启动 | 查明本机已有进程，停止你自己启动的服务，或为 E2E 同时换端口和数据库；不要杀未知进程 |
| real 缺少模型配置而退出 | 设置 Key 和模型名；它不会静默切回 fixture。不要粘贴真实 Key 到日志或工单 |
| `/library` 不再显示旧列表 | 当前统一为 `/` 工作台；旧书签通过 `navigation.ts` 转换，不会创建会话或调用模型 |

## API 和运行状态

| 状态 / 现象 | 含义与下一步 |
| --- | --- |
| 202 | 已接受，不是已完成；读取 run 或订阅 SSE |
| 409 | 可能是版本过期、作用域/输入冲突、未发布或来源失效；读取公开错误码及最新状态，不统一自动重试 |
| 422 | 请求字段或领域约束不合法；先核对 OpenAPI 和图谱/组件规则 |
| 429 | 准入已满；保留原命令与标识，查询后显式恢复，不能靠改 ID 绕过 |
| 刷新后 interrupted | 上次任务没有完整结束；重启只恢复状态，不自动执行模型 |
| 取消后仍不能开始新任务 | 公开取消已完成，但后台阻塞调用尚未退出，暂仍占并发名额 |
| SSE 断开 | 不代表任务取消；先 GET run，对照快照与 cursor 恢复 |
| 同一请求返回原结果 | 幂等复用的正常行为；失败后的 retry 与显式新任务不是同一概念 |

更细的 session/request/root、预算与重试契约见 [API 手册](../api-guide.md)和[可靠性手册](../RELIABILITY.md)。不要对未知结果直接重新 POST。

## 学习与资料

- **浏览节点后，聊天仍回答原节点**：这是预期。已有会话作用域不随浏览改变；选择“开始学习此节点”新建对话。
- **新会话能看到旧教材，但没有旧聊天**：教材、题目和成绩属于节点，transcript 属于会话，不自动合并。
- **阅读后掌握度没变**：只有正式作答计分，章节 ACK 和模型自述不计成绩。
- **上传成功但搜不到**：等待解析 ready，检查目标/节点显式绑定与查询。节点练习/学习包不会自动继承只有目标级的绑定。
- **扫描 PDF 无文本**：当前不支持 OCR，换成可提取文本的 PDF、UTF-8 TXT 或 Markdown。
- **引用 C1 点击错误**：C1 仅属于当前回答或产物，不能跨回答、题目、学习包共用；解绑、删除、版本/hash/位置变化会使旧定位失效。
- **有绑定却生成失败**：资料空召回时明确失败，不能让模型静默改用通用知识冒充有来源。

## 文档站

- 使用 `npm.cmd ci` 后再启动 `npm.cmd run docs:dev`；不需要启动 Python/API。
- 构建死链先修 Markdown 的真实相对路径，不设置忽略死链。章节锚点和内容事实仍需人工核对。
- 搜索是浏览器内本地索引，不配置外部搜索账号；生产搜索以最新 `docs:build` 的内容为准。
- 输出目录、缓存和 Playwright 结果是生成物，不加入版本控制。文档维护与命令见[维护指南](documentation.md)。

## 提问时带上什么

写明使用哪个命令、fixture/real、相关非敏感 run ID、预期和实际行为、公开错误码、复现最小步骤和是否涉及重启。不要上传 `.env`、API Key、日常数据库、私人资料、供应商原始响应或未脱敏的浏览器 trace。
