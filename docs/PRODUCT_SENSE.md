# 产品判断原则

面向本地单个学习者，帮助其理解知识结构并围绕节点持续探索，而不是管理项目排期。

- **知识地图优先**：主题、子主题、知识点组织学习内容；路线只是图谱的一种使用方式。成果、基础、时间可提供参考，不强迫兴趣变成项目交付或必填问卷。
- **从主题直接开始**：首页默认提出学习意图，普通聊天是明确的辅助入口。图谱发布后直接衔接节点选择与开始/继续，资料、教材和练习不作为入场配置要求。
- **共用界面，不混用会话**：目标创建、普通交流与节点学习可以共用工作台；模式、图谱和会话焦点必须可见。浏览节点不是修改对话范围。
- **新建与继续有不同含义**：开始学习新建独立聊天；继续学习恢复指定历史。教材、题目、成绩归属节点，不因重开会话而丢失，也不意味着自动读取其他聊天。
- **用户决定边界**：模型提出草稿，用户明确确认和发布。切换模式、刷新、浏览和恢复读取不代表授权模型生成。
- **内容可读且可追问**：长教材不塞满消息气泡；在主区阅读，解释紧邻章节、步骤或题目，保留来源和版本。
- **先保证可信恢复**：宁可要求一次显式恢复，也不因网络不确定而自动重复生成。fixture 只证明契约，不证明真实内容质量。
- **积累也能清理**：删除会话不抹除节点共享资产；放弃目标或删除图谱明确清理主题专属记录，原始资料独立保留。不把隐藏冒充删除，不因删除自动取消仍在执行的任务；结果不确定时先查询再由用户决定。
- **一个入口，保留能力**：资料、原文、图谱编辑和提案审核是工作台工具，不是第二套应用。工具导航保留原会话，资料绑定范围与聊天范围独立；旧地址只读兼容，不为了删除页面而丢弃学习记录。
