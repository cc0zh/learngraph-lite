# 开发者文档与同源文档站

## 目标、范围与风险

- 目标：帮助新加入的开发者启动应用、理解领域与调用路径、独立修改业务功能并选择验证。仓库 Markdown 与本地文档站使用同一份源。
- 包含：新人阅读路径、概念与架构指南、关键链路、修改指南、测试与排错入口；VitePress 导航、中文本地搜索、构建与预览命令；同步 README、贡献入口和 CI。
- 不包含：业务功能修改、公开部署、收费模型调用、历史记录的大规模搬迁。不将历史测试或 fixture 结果写成当前真实模型质量证明。
- 风险：已有大量未提交的业务与文档改动。保留现有工作区，不重置、不自动提交；从当前源码核对事实，不仅依据旧 README。保留规范、API 和历史文件的稳定路径。
- 安全：站点只构建 docs 内的正式知识，不复制 .env、数据库或本地证据；源码链接使用当前仓库相对路径，不猜测远端仓库地址。
- 授权：用户授权新建分支并本地实施，分支为 `docs/developer-handbook`；未授权发布或部署。

## 交付文件

- `docs/index.md`：新人阅读顺序、按问题查阅与边界说明。
- `docs/developer/`：首次运行、配置、概念、架构、六条业务链路、业务改动、测试、排错及文档维护，共九页。
- `docs/.vitepress/`：同源站点、中文侧栏/目录、本地搜索、系统字体主题；`docs/license.md` 为同源许可入口。
- `package.json`、`package-lock.json`：固定 VitePress 1.6.4、开发/构建/预览和独立文档测试命令。
- `.github/workflows/ci.yml`：各平台构建文档、Linux 独立文档浏览器回归；没有发布或部署步骤。
- `tests/docs*`、`tests/tooling.test.cjs`、`scripts/lib/`：文档浏览器契约、源码导出与缓存排除回归；README、贡献指南和 CI/CD 同步入口。
- 修正 history 模板占位文本被 Markdown 属性插件误解析的问题；旧学习文档的源码链接改为编辑器路径，避免伪装为站内页面。
