# 引导式目标澄清与可理解路线确认

## 目标、范围与风险

- 用户从一句意图开始；最多三个关键问题，支持选项、自定义、跳过与说明原因。摘要可修改，明确确认时一次保存，默认假设及自述基础的未验证性质可见。
- 路线以依赖顺序展示阶段、必要性、成果和预计投入；明确说明实践与验证的安排。普通用户无需编辑优先级/依赖即可发布，保留高级编辑。
- 支持太难、太宽、已有基础、调整重点反馈，重新生成草稿，仍须用户明确发布。
- 包含前端、后端确认/反馈契约、持久化兼容、离线及浏览器测试。排除真实模型付费验证、部署和通用课程质量保证。
- 风险：未保存编辑与异步响应冲突、反馈重试语义、旧数据库兼容；沿用版本锁、显式任务恢复和严格候选校验。
