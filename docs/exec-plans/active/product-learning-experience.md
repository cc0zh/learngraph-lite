# 现有产品方向内的真实学习体验与求职交付

## 目标、范围与风险

- 目标：在不更换 LearnGraph Lite 产品方向的前提下，完成一个真实学习案例，判断知识地图、节点内容积累与继续学习的价值，再整理代表性演示和可解释的产品取舍。
- 当前主题：概率与统计，重点为条件概率、分布与统计直觉。原主题为工具调用与 Agent 运行机制，用户后续要求更换；这只改变体验内容，不重新定义个人学习产品。
- 体验与讨论阶段包含：非敏感短学习资料、自然用户旅程、本人反馈和事实记录框架、文档导航与检查；后续已授权实施范围见“第一轮实施”。
- 始终不包含：重定义用户或学习目标、强制考核、无关 Bug 追查、覆盖另一会话改动，以及未经授权的真实模型请求。
- 授权：用户同意保持方向、先完成真实案例与核心体验，再整理求职作品；已选择本轮学习主题，并另行同意沿用现有配置、整轮最多 14 次供应商请求，仅发送本轮非敏感笔记、问题及必要上下文。额外轮次或普通聊天对照仍须另行确认。
- 风险与缓解：模型完成不等于内容正确；助手操作不等于本人学习；一次体验不证明教育效果；准备文件不标成已验收。使用新独立数据空间与既有限次入口，不读取日常私有证据。

### 第一轮实施：最小使用闭环

后续用户明确“继续执行”，授权本节范围的本地编辑、测试及本轮问题修复；此前仅文档阶段的“不改业务代码”不再适用于本节。学习包具体形态、本人教学效果、内容可信度、新增付费请求和最终求职交付仍不在本轮完成声明内。

- 使用主线：首页直接提出学习主题并开始规划，普通对话为独立次级入口；确认目标、审核图谱仍需显式操作，不因导航或刷新调用模型。发布后可直接选择节点进入学习，资料与练习保持按需。
- 会话删除：清理此会话及专属运行/解释历史，不连带清除共享节点教材、题目、成绩；派生目标创建对话不单独删除，随主题清理。
- 主题删除：包括放弃未完成目标和删除已发布图谱，按当前版本清理该主题的规划、学习资产、会话、运行、提案、绑定；独立上传原始资料与其他主题保留。确认框解释影响，不执行现有用户数据清理。
- 安全边界：仍有排队/执行工作线程时拒绝删除，公开取消不等于线程退出；删除与准入、持久清理协调，避免部分删除及旧请求复活。使用最少 ID 删除标记阻止迟到重放，不保留已删正文冒充删除。
- 协作：开始时前端没有未提交文件，沿用已提交视觉方案而不重新设计；已有 `application/learning_agent.py`、`tests/test_learning_agent.py` 等其他会话改动保留，不覆盖。后端由独立工作代理负责，主会话负责前端与文档，测试文件另行按边界分工。
- 验证：先写相关回归，使用临时 SQLite 与明确 fixture 装配；不连接当前真实服务、不重置已耗尽的 14 次额度、不启动付费 smoke。覆盖会话删除保留资产、主题删除隔离、活跃任务、版本冲突、刷新/重启、删除响应不确定和重复提交。
- 交付范围：完整主线与安全生命周期，不新增仪表盘、自动学习路线、长期记忆、回收站、跨会话合并或任意代码执行。

实施结果：根路径直接进入主题创建，普通聊天以 `mode=chat` 显式进入；规划发布后提供主区节点入口，可直接开始或继续独立会话，无需先绑定资料/生成教材。学习空间支持会话删除、放弃目标、图谱删除及范围确认。后端通过应用生命周期端口与同连接 SQLite 事务清理，loop 在实际线程退出后才允许删除，提交成功后同步内存记录；仅保留 goal/session/run ID 标记阻止旧请求复活。

专项回归先发现并修复三项前端边界：目标删除失响应后刷新无法从已消失目录找回本地命令归属，改为请求前保存已知会话 ID；查询错误改在删除状态区域说明；已删 session 的迟到 POST 回执不再写回命令缓存。只读审查另提出两项持久 SDK 风险，均先以测试复现失败，再在 SQLite 准入事务校验独立目录/父子作用域，并以 run ID 删除标记拒绝旧回答缓存/生成请求投影保存；不从 loop 锁内反向获取目录锁。

新教材/解释请求携带不可变 `parent_session_id`，恢复旧请求保留原指纹。旧无父关系的随机子 session 不猜测会话归属，仅删除整个主题时完整归集，这是已知兼容限制；运行边界仍为单 API 进程。本轮没有处理旧存储异常、内容语义问题或扩建学习包。
